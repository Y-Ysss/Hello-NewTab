# Hello NewTab

Hello NewTab replaces your browser's default New Tab page with a bookmark-focused dashboard.

## Overview

This extension helps you access bookmarks faster by showing bookmark folders in a clean layout, with built-in search and visual customization.

## Features

- Bookmark list grouped by folder
- Bookmark search
- Theme customization (Style / Theme / Accent Color)
- Background pattern customization

## Usage

1. Open a new tab in Chrome or another Chromium-based browser.
2. Your bookmarks are shown by folder.
3. Click a bookmark title (or favicon) to open the page.
4. Open the Options page to customize style, theme, color, and background patterns.

## Installation

### Chrome Web Store

[Chrome Web Store - Hello NewTab](https://chrome.google.com/webstore/detail/hello-newtab/gcheeeiicddnpmmlpidigaepkfhpedfb)

### Load unpacked (development)

1. Open `chrome://extensions`.
2. Enable Developer mode.
3. Click Load unpacked.
4. Select the `src` directory in this repository.
