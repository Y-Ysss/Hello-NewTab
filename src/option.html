Regular expression patterns
Pattern Description
^... Match when the following text is at the start of the string
...$ Match when the preceding text is at the end of the string
. Match any single character
...* Greedy match for zero or more repetitions of the preceding character
...+ Greedy match for one or more repetitions of the preceding character
...? Greedy match for zero or one occurrence of the preceding character
...+? Lazy match for one or more repetitions of the preceding character
...*? Lazy match for zero or more repetitions of the preceding character
...?? Lazy match for zero or one occurrence of the preceding character
...|... Match either the left or right condition (OR)
[...] Match any one character inside the brackets
[^...] Match any character not inside the brackets
(...) Group the pattern
{n} Specify the number of repetitions
{min, } Specify only the minimum number of repetitions
{min,max} Greedy match for repetitions from the minimum to maximum
{min,max}? Lazy match for repetitions from the minimum to maximum
